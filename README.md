****🎬 Netflix Content Analysis Dashboard (Power BI)****

📌 **Project Overview**
This project presents an end-to-end Power BI dashboard built to analyze Netflix’s global content library. The goal is to transform raw Netflix data into actionable business insights using data cleaning, DAX calculations, and interactive visualizations.

The dashboard is designed with an executive-first approach, combining KPIs, trends, and deep-dive analysis across time, geography, and content categories.

**📊 Key Features**
* Executive KPI view with total content, movies vs TV shows, YoY growth, and peak year
* Year-wise content trend analysis
* Top countries contributing to Netflix content
* Global content distribution using map visuals
* Genre and rating distribution
* Top actors and directors analysis
* Interactive slicers for year and content type
* Insight-focused cards highlighting key findings

**🔍 Key Insights**
* Netflix’s content additions peaked around 2018, followed by a noticeable slowdown.
* The United States is the largest contributor to Netflix’s content library.
* Dramas dominate the genre distribution.
* Recent years show negative YoY growth, indicating a potential strategic shift in content acquisition.
* Movies and TV shows show distinct growth patterns over time.

**🛠 Tools & Technologies**
* Power BI Desktop
* Power Query (Data Cleaning & Transformation)
* DAX (Measures for KPIs, YoY Growth, Top N, Averages)
* Excel / CSV Dataset

**🧩 Data Preparation**
* Handled missing and inconsistent values
* Standardized text columns (Trim/Clean)
* Created calculated measures for analytical insights
* Applied Top N and ranking logic for categorical analysis
